# Stitch Homework Challenger 🎓

This repository contains the source code and design assets for the Homework Challenger project, a multi-platform concept for student task management.

## 📂 Repository Structure

- **`homework-app/`**: The main web application built with Vue 3, Vite, and Tailwind CSS. This is the primary functional version of the project.
- **`data_management_screen/`**: Design assets/logic for data management features.
- **`monthly_analytics_screen/`**: Design assets/logic for monthly overview visualizations.
- **`reward_points_screen/`**: Design assets/logic for the gamified points system.
- **`today's_tasks_screen/`**: Design assets/logic for the daily dashboard.
- **`weekly_analytics_screen/`**: Design assets/logic for weekly progress tracking.

## 🚀 Main Application

The primary implementation is located in the `homework-app` directory. It features:
- Task tracking with subject categorization.
- Real-time points accumulation.
- Historical data analytics with interactive charts.
- Full offline support via IndexedDB.
- Multi-language support (English & Chinese).

### Quick Start
```bash
cd homework-app
npm install
npm run dev
```

For more detailed information about the web app, please refer to the [homework-app README](./homework-app/README.md).
